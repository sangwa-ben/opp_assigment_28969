# AUCA_ID School Management System

A console-based Java school-management application. It manages departments,
students, teachers, administrators, courses, classrooms, enrollments, assessments,
fee payments, library books, and loans. Users can register, view, search, and
update records, review student summaries and payment history, and borrow or return
books.

Records are held in memory and are lost when the application exits. Registration
forms support validation, review, edits, and cancellation; related records are
selected from numbered lists.
